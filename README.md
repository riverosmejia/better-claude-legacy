# better-claude-legacy

Fork congelado de [midudev/better-claude](https://github.com/midudev/better-claude): sus once plugins
y mods para Claude Code, tal como estaban, como referencia.

**No está mantenido.** Lo que se adaptó a Hermes Agent vive en
[better-hermes](https://github.com/riverosmejia/better-hermes), una pieza por repo:

- [better-peek](https://github.com/riverosmejia/better-peek) — las rutas de una respuesta se vuelven
  ficheros que puedes ver y abrir (`/peek`, widget del TUI y parche opcional).

Este repo existe para no perder el punto de partida y para poder mirar cómo estaba hecho el original
(`plugins/quick-peek/hooks/paths.ts` es el origen del port). Licencia MIT, como el original.
